## What is BirdpaperICON

This is a `Vue3` icon component library generated from the open-source icon set - [RemixIcon](https://remixicon.com/). It makes it convenient for developers to use icons in `Vue` components with support for common properties and operations. For details, see [API Properties](/en/doc/quickStart#icon-properties).

![](https://cos.birdpaper.design/birdpaper-icon/v1/assets/icon-bg.png)

In early 2024, I proposed to the Remix Icon author **_Jimmy Cheung_** the idea of further encapsulating `svg` icons into `Vue3` components based on developer conventions.

With the author's permission, this project has now officially released its first `v1` version, hoping to help developers better use this excellent icon library.

Once again, this project is for learning and reference only, not for commercial use. Contributions are welcome — let's maintain this project together.
